## How I work with AI
Most of what I build is now AI-assisted, mainly with Claude Code. My approach:

- **Plan first.** I write the requirements and user stories before any code gets generated.
- **Direct the build.** I break the work into small tasks and prompt from the user stories.
- **Check everything.** I test what the AI produces against what it is meant to do and fix or reject what doesn't fit.
- **Learn as I go.** I use each project to understand the code, not just ship it and I document decisions along the way.
- **Automate the boring stuff.** If something is manual and repetitive, I will try to script it.
